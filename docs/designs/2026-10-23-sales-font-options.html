总览页字体方案 3 组视觉对比

同一份总览页内容，分别用系统字体、Inter + Noto Sans SC、IBM Plex Sans + Noto Sans SC 渲染。 重点看中文小字号、英文缩写、金额、表格数字和编号。

01

系统默认

当前线上方案：Segoe UI / 苹方 / 微软雅黑，零字体依赖。

零依赖 跨平台差异
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif
优点：无需字体文件，离线可用，加载最快。 取舍：Windows 与 macOS 观感不同，雅黑在 12px 下略挤。
02

Inter + Noto Sans SC

跨平台一致，英文和数字清晰，中文小字号稳定。

推荐 现代数据台 数字清晰
"Inter", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif
优点：中英文气质统一，金额和表格数字更利落。 取舍：需要自托管 Inter + Noto Sans SC 的 WOFF2 子集。
03

IBM Plex Sans + Noto Sans SC

更偏企业与工业理性，适合审批、合同和密集表格。

企业理性 表格友好
"IBM Plex Sans", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif
优点：数字和英文更有“系统感”，和审批流很搭。 取舍：整体比 Inter 更硬，年轻感略弱。
04

推荐落地 02 Inter + Noto Sans SC

总览页最均衡：中文清楚、英文利落、数字稳定。

零依赖备选 01 系统默认

离线优先、暂时不想引入字体文件时继续使用。

企业感备选 03 IBM Plex Sans

如果整体产品更偏审批、合同、流程，可以选它。

注：本页通过 Google Fonts 加载字体，仅用于视觉确认；正式落地建议自托管 WOFF2 并做常用字子集。Barlow 只建议用于 24px 以上的指标大数字，不用于正文和表格。
