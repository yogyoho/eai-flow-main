### 2.3 `14_block_model.json`（块段/资源量参数）——两级颗粒度（走查新增定稿）

样例正文**不含逐块段明细**（在附表，样例 docx 未附）——管线必须支持两级输入：

- **A级（块段级，优先）**：`blocks: [{矿体, 块段号, 类别TM/KZ/TD, 品级工业/低品位, 投影面积S(m2), 平均水平投影厚度M(m), 块段品位C(%), 体重D(t/m3)}]`

- **B级（矿体×类别汇总级，降级可用）**：`aggregates: [{矿体, 类别, 品级, 矿石量(万吨), 金属量(t), 品位(%)}]`

- 矿体清单字段：`ore_bodies: [{id:"马Ⅰ-1", group:"马柱硐", groups_in_table:8}]`
  ⚠️ 走查发现：**矿体编号前缀≠矿体群判定依据**（Ⅰ号群含 `1-4/1-6/1-7` 阿拉伯前缀的低品位矿体），群归属必须显式字段，禁从编号推断。

## 3. 公式链完整清单（formula_engine 登记）

| # | 公式 | 输入→输出 | 精度 |
|---|---|---|---|
| L1 | `M = L·(sinα·cosβ·cosγ ± cosα·sinβ)` | 单样：取样长/矿体倾角/坡度/夹角→真厚 | 0.01m |
| L2 | `I = M/sinα`；`H = M/cosα`（= `I/cosϕ`） | 真厚→水平厚/水平投影厚 | 0.01m |
| L3 | 单工程厚 = Σ单样真厚 | | 0.01m |
| L4 | 单工程品位 = Σ(Cᵢ·Lᵢ)/ΣLᵢ | 样长加权 | 0.01% |
| L5 | 块段均厚 = Σmᵢ/n | 算术平均 | 0.01m |
| L6 | 块段品位 = Σ(C工程ᵢ·Iᵢ)/ΣIᵢ | 水平厚度加权 | 0.01% |
| L7 | `V=S×M`；`Q=V×D`；`P=Q×C/100` | 面积m²×厚m×体重t/m³；品位%转吨 | 矿石量万吨2位、金属量整数 |
| L8 | 矿体品位 = Σ(Q块ᵢ·C块ᵢ)/ΣQ块ᵢ | 矿石量加权 | 0.01% |
| L9 | 表8-2 小计/总计 = Σ行 | 按类别×品级分组 | 同上 |
| L10 | 增量 = 本次 − split_extent（按 code_mapping 对齐类别） | 表8-3 | 同上 |
| L11 | 伴生 `P_Ag(kg) = Q矿石(t)×C_Ag(g/t)/1000` | 主元素矿石量×伴生品位 | 整数kg |
| L12 | 验证误差率 = (块段法−水平断面法)/水平断面法×100% | 表8-4 | 2位% |
| W1 | 比拟法 `Q = Q₀·(F/F₀)·√(S/S₀)` | ch6 涌水量（见§5.2） | 整数m³/d |

**舍入策略（走查定稿）**：8.4.6「四舍六入五逢奇进偶舍」= ROUND_HALF_EVEN（银行家舍入）。formula_engine 用 `decimal.Decimal` + `quantize(ROUND_HALF_EVEN)` 显式实现——禁用 float `round()`（二进制表示陷阱，如 `round(2.675,2)=2.67`）。
**量纲陷阱**：S 为**水平投影面积**（非真面积）、M 为**水平投影厚度**（非真厚）——V=S×M 只有在垂直纵投影法下自洽；万吨换算 ÷10000；品位 % 参与乘法时 ÷100。formula_engine 单位注记字段必填。

## 5. 两处口径定稿（回写 spec）

### 5.1 8.8.3 增量句口径（原 Open Question → 定稿）

**总量层四口径**：工业矿 TM+KZ / 工业矿 TD / 尚难利用 KZ / 尚难利用 TD，每口径给「矿石量+金属量」两个增量数，数据源=表8-3 合计行差值。**不做**逐矿体叙述（逐矿体已在表8-3 内）。
8.8.3(2) 原因分析按**两组拆分**：新增矿体组（Ⅰ/Ⅱ群+马Ⅰ-6，增量=本次值）+ 对比矿体组（马Ⅰ-1/马Ⅱ-1/马Ⅲ-3，增量=本次−2011）；C6 保证两组之和=总增量。

### 5.2 比拟法参数口径（原 Risk「无法复现」→ 定稿）

公式已从 MathType OLE 的 WMF 预览恢复（视觉转录，2026-08-21）：

> **Q = Q₀ × (F/F₀) × √(S/S₀)**（标准比拟法，与式中文字说明完全吻合）

代入样例参数（S/S₀=1、F/F₀=169285/114671=1.4763）：
- Q最小 = 6898×1.4763 = **10183 m³/d**（样例写 908）
- Q最大 = 12285×1.4763 = **18136 m³/d**（样例写 5531）

**定性：样例结果数字错误**（不可复现的内部证据：908/5531=0.164 ≠ 6898/12285=0.562——任何单一乘法公式下两比值必须相等，样例连自身互洽都不满足；疑为套用他项目数字）。
**处理**：W1 按恢复的公式体录入 formula_engine；用户参数代入正确计算；样例 908/5531 记为「样例未复现」——**eval 断言用 10183/18136（公式正确值），不断言样例原值**；报告正文若用户提供类似不自洽数据，管线以公式重算值为准并在走查报告中提示差异（不静默抄录、不编造解释）。
