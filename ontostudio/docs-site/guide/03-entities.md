# 03 实体库

> 对齐：`frontend/src/pages/EntitiesPage.tsx` @ 2026-10-06

## 入口

侧边栏「知识层 → 实体库」。全量实体检索表格——图谱的"台账视图"，不画图，只看数。

## 核心操作

- **实体检索面板**：右侧三个过滤钮——**域 / 类型 / 状态**；类型选择器来自 registry 对象类型清单（图谱实体/关系/证据 + eia 实体/关系双透镜）
- **列序**：实体 / 类型 / 规范名（norm）/ 置信度 / 状态 / 提及 / 更新 / 行操作——没有裸主键列，别找 uuid
- **行点击 → 右侧抽屉**（带遮罩）：该实体完整属性与关联链接
- **行操作按状态分流**：pending → 「去审核」直达消解；merged → 「查看合并」看归入了谁；其余 → 详情抽屉
- **分页**：每页 50，真实上一页/下一页

## 结果解读

- **状态列**是审阅闭环的镜像：pending_review=待审、active=已入图、rejected=已驳回、merged=已合并（[审阅闭环](./review-loop)）
- **提及列**：该实体被多少条证据（mention）引用——高置信但零提及的实体审的时候多留个心眼

## 常见问题

- **导出当前筛选 / 批量送审按钮点了没反应**：规划中（tooltip 有标注），尚未接真
- **搜索不到刚抽取的实体**：状态过滤默认包含 pending？若只看 active 当然没有——未确认实体不在图上，但台账里应该在；两处都没有才是 bug，先查任务是否完成
