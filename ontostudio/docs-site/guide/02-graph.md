# 02 图谱浏览

> 对齐：`frontend/src/components/OntologyPage.tsx`（语义地图）@ 2026-10-06

## 入口

侧边栏「知识层 → 图谱浏览」。本体语义地图的主界面：顶栏（标题/检索/registry 指纹 chip）+ 三视图分段 + 图画布 + 右栏 300px 详情 tabs。

## 三视图

| 视图 | 用途 |
|---|---|
| **地图** | 图画布：看实体/关系拓扑，点节点定位 focusNode，右栏看属性与关联链接 |
| **概览** | registry 结构总览（类/谓词/域） |
| **实体消解** | 即「04 消解审核」视图——待审确认/合并（详见 [审阅闭环](./review-loop)） |

## 核心操作

- **检索**：顶栏搜索对已加载图节点按 label 子串过滤，候选下拉点选后画布定位该节点（客户端过滤的降级实现——只搜已加载节点，全量检索去 [03 实体库](./03-entities)）
- **右栏 tabs**：选中节点的属性、关联、证据链
- **刷新**：消解操作（merge/unmerge）成功后图自动全量失效重载

## 结果解读

- 顶栏 registry 指纹 chip 变了 = 建模器那边保存过新版本——地图是按新 schema 重编后的形态
- 待复核实体数徽标来自 doc-graph resolution 接口，与侧栏红点同源

## 常见问题

- **搜索搜不到某个实体**：检索只覆盖已加载节点；用实体库全量检索，或先缩放画布加载对应区域
- **图空/加载失败**：先看 [01 总览](./01-dashboard) 校验状态与数据面——图库可能还没装载（`formal/load`）
