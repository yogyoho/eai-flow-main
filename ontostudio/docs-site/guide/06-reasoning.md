# 06 推理工作台

> 对齐：`frontend/src/pages/ReasoningPage.tsx` @ 2026-10-06

## 入口

侧边栏「建模层 → 推理工作台」。跑推理、看物化统计与规则表。**推理是重操作**——按钮触发，不做后台常跑。

## 核心操作

- **infer**：一次调用跑双层推理（[owlrl 闭包](../concepts/owlrl) → `graph:entailment` + [CONSTRUCT 派生](../concepts/sparql-construct) → `graph:derived:*`），返回输入三元组数、物化三元组数、各规则派生计数
- **规则表**：注册规则的清单与状态（启停走治理动作，有审计）
- 每次跑完，[01 总览](./01-dashboard) 的"推理物化"瓦片随之更新（同缓存 key）

## 结果解读

- **物化数 ≠ 新知识数**：闭包总规模含大量平凡传递（如 subClassOf 链），有价值的派生结论是少数——按规则派生计数看，别看总数
- **某规则派生数为 0**：先查链首类型在图上有没有实例（owlrl 属性链"链首无实例静默零推断"是真实踩坑，见[概念页](../concepts/owlrl#常见坑)），再怀疑规则本身
- **跑到工作预算**：`max_derived_reached` 等标志=true 表示到达预算上限——不必然截断，看数据完整性再判断

## 规划态区块

解释视图与 CQ 验收单两个区块当前是**规划态展示（带水印）**——推理验证面还是黑盒（"这条结论哪来的"暂无处可查），已入主系统 TODOS「推理白盒化」，触发条件驱动开工。在那之前，规则触发轨迹可走 doc-graph MCP 的 `evaluate_rules`（现算现返带轨迹）。

## 常见问题

- **infer 要多久**：取决于图规模与规则数；校验中心的重是 20 秒级，推理同级或更久——跑之前确认没人在做装载等互斥重操作
- **改了规则要重跑吗**：要。断言图或规则变了，旧结果就陈旧——infer 后再去校验中心复检
