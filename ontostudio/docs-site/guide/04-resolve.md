# 04 消解审核

> 对齐：OntologyPage 消解视图 + ResolutionPanel @ 2026-10-06

## 入口

侧边栏「知识层 → 消解审核」（即图谱浏览的「实体消解」视图）。**完整状态机、队列读法、与 Agent 可见性的关系请读专题页：[审阅闭环](./review-loop)**——本页只放快速操作。

## 快速操作

| 场景 | 操作 |
|---|---|
| 逐条过审 | 待审列表按置信度升序，点开实体核对属性与证据 quote → 确认/驳回 |
| 同名异写合并 | candidate 归入 canonical（保留最完整规范名一方）→ merge，dg_merges 留痕 |
| 合并错了 | unmerge（拿 merge_id）撤销，candidate 回到待审 |
| 批量确认 | Agent 预审分层（方案 C）未上线前无批量——量大自然靠搜索定位逐条过 |

## 边界

- **第一版仅超管可审**（面板横幅自述）
- relation 边暂无独立审批通道（随实体整链确认），主系统 TODOS 在册

## 常见问题

- **确认了怎么图谱浏览里没有**：确认即投影，画布若未重载点刷新；仍没有 → 看 [07 校验中心](./07-validation) 数据治理是否把它当孤儿清了
- **横幅提示"仅超管可审"**：当前账号权限不足，找管理员
