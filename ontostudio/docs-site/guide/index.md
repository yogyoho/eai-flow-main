# 功能操作指南

OntoStudio 九大模块的操作要点。左侧菜单与页面编号一一对应。

## 01 工作台总览

运营仪表盘：实体/关系/推理物化/待审四瓦片 + 域健康表 + 校验状态/数据面/抽取活动三卡。

- 点击**待审实体**瓦片直达消解审核
- 「运行推理」显式触发全量推理（平时仅展示缓存结果）
- 「全量装载（对账）」重读数据库刷新图面——投影失败后的自愈手段

## 02 图谱浏览

断言图交互视图。工具栏：**状态着色**（待审琥珀/驳回红/已确认蓝）/ **只看已确认** / **社区着色**（Louvain 聚类）。

- 点击节点 → 右侧详情抽屉（属性三元组/关联链接）
- 顶部检索可定位实体

## 03 实体库

全域实例检索表。

- 类型下拉切换对象类型（各类型属性不同，无混合视图）
- 域/状态过滤器 + 全文搜索 + 页码分页（每页 10/25/50/100 可选）
- 行点击打开详情抽屉；待审行可「去审核」直达消解

## 04 消解审核

人审闭环主工作面。

- 左列待确认实体卡：**确认入图** / **驳回**——确认后断言图即时更新（行内绿勾/黄警反馈）
- 点选卡片 → 右列加载 Top 5 相似建议 → 合并（可撤销）或不合并
- 操作反馈四态：成功绿勾 / degraded 黄警（重跑全量装载自愈）/ 409 中性提示 / 在途 spinner
- 当前仅 superadmin 可审；正式审阅角色授权为后续批次

## 05 本体建模器

双模式本体编辑器。

- **可视化模式**：真实类层次画布（节点可拖拽移位、实例计数）——点选类 → 右栏编辑 label/定义、增删父类（=连线编辑）；「＋新建类」追加草稿
- **YAML 源码模式**：整篇编辑（结构变更/公理/父类/键在此做）
- **保存前必须通过校验**；保存即 SHA 热重载，下一次推理用新词表
- 换域文件请用左栏列表（当前 registry = doc_graph + eia 两域）

## 06 推理工作台

OWL 闭包 + 规则推导运行器。

- 「运行推理」全量重算（物化三元组/规则命中/耗时统计）
- CQ 验收单与解释视图为规划项（见更新记录）

## 07 校验中心

SHACL 形状校验 + 国标符合性套件（C1-C5）。

- 「重新校验」随全量装载/推理后执行
- 违规按级别（错误/警告）列出，定位到形状与目标实体

## 08 抽取导入

抽取生产线视图。

- 「从主系统线程导入」触发全量装载（dg_* 已有数据时即对账）
- 任务队列/置信度分布/证据链引文——任务概念后端为规划项
- 生产线 regex/v1（确定性正则，与 eia.yaml 枚举严格同名）

## 09 导出互操作

- Turtle / JSON-LD 导出与下载（图面可选 asserted/全量）
- **全量装载（对账）**按钮即数据面自愈入口
- 本体导入（国标 6.1.2）为规划项
