# 09 导出互操作

> 对齐：`frontend/src/pages/ExportPage.tsx` @ 2026-10-06

## 入口

侧边栏「管线 → 导出互操作」。图的三个出口：交付导出 / 快照存档 / 数据回灌。

## 核心操作

### 导出

| 档位 | 内容 | 用途 |
|---|---|---|
| Turtle all | 断言图全量 | 交付/互操作正典 |
| Turtle 含派生档 | 断言 + entailment + derived | 完整快照语义（抽屉概念见 [TriG 快照](../concepts/trig-snapshots)） |
| JSON-LD schema | schema 图 | 给 REST/前端生态消费 |

序列化格式细节与 C2 往返校验见 [Turtle 与 JSON-LD 1.1](../concepts/turtle-jsonld)。

### 快照（TriG 全图，D8 落地）

- **落盘 / 清单 / 恢复 / 删除**四件套；恢复带**自动回滚点**（恢复前自动拍一份当前态，错了能回来）
- **每日 06:00 自动快照 + 30 天滚动清理**（G1 调度）——重要时点（评审基线）手工另存图库之外
- 「IRI 机械可逆可回导」由 TriG 快照成真：Turtle 交付物是压平三元组形态，快照才带完整图边界

### 从主系统线程导入（formal/load）

全量装载 = 对账：把主系统线程产物重灌进图。**重写图数据全表（耗时数十秒）**，有 `window.confirm` 二次确认，失败信息可见。跑完去校验中心复检。

## 常见问题

- **导出和快照有什么区别**：导出是交付物（给人/给外部系统），快照是时点存档（给恢复/审计）——格式都是 Turtle 系，用途不同
- **恢复把别人刚确认的数据冲掉了**：恢复覆盖当前图；恢复自带回滚点，立即恢复回去并协调队伍
- **装载失败**：看页面错误信息（失败可见），常见是源数据校验不过——先在主系统侧修数据
