# 本体地基：三元组与 RDFS/OWL

> 对齐：`ontostudio/backend/app/ontology/registry/` + `kernel/iri.py` @ 2026-10-06

## 一句话类比

三元组就是「主语 谓语 宾语」的原子陈述句——"矸石山 是一种 工业固废""敏感点 距离 井田边界 500 米"。**本体（ontology）**则是关于这些句子的字典+语法书：哪些词存在、词是什么意思、什么句子合法。

## 在 OntoStudio 里对应什么

**三元组（triple）**：知识图谱的最小单元，`主语 → 谓语 → 宾语`。主语和谓语必须是 **IRI**（国际化资源标识符——全局唯一的名字，不必是可以访问的网址）；宾语可以是 IRI，也可以是**字面量**（数字、字符串、日期）。

**RDFS**：最薄的一层"语法书"，提供 `subClassOf`（子类）、`label`（人读标签）、`domain`/`range`（属性取值范围）等基本词表。OntoStudio 的类层级就是用它声明的。

**OWL**：更厚的语法书，能表达公理（"这两个类互斥""该属性传递"）。**本系统只轻量使用 OWL 的类/属性声明，不做公理级形式化建模**——这是诚实边界，见 [国标符合性 · 边界与规划](../reference/gbt-48000#边界与规划-诚实声明)。

**命名空间与前缀**：IRI 很长，用前缀缩写。如 `dg:` 展开为 `http://ontostudio.example/dg#`，`dg:graph_entity` 就是完整 IRI 的速记。每个域有自己的命名空间，登记在 registry 中。

**registry**：OntoStudio 的"字典+语法书"本体——`ontostudio/backend/app/ontology/registry/` 下的 yaml 文件（`doc_graph.yaml`、`eia.yaml`、`_manifest.yaml`），声明每个域有哪些对象类型（类）、属性列、链接（谓词）。建模器页编辑的就是它的草稿。

## 你在哪能看到/操作它

- **05 本体建模器**：编辑 registry 草稿、validate 校验、保存——"改语法书"的地方
- **02 图谱浏览 / 03 实体库**：看按这套词表组织出来的实例（句子）
- **IRI 规约**：实例 IRI 形如 `命名空间 + id/<uuid>`，机械可逆——这正是国标符合性 C1 校验的对象（[GB/T 48000.3 符合性](../reference/gbt-48000)）

## 常见坑

- **IRI ≠ URL**：IRI 只要求全局唯一且机械可逆，不要求浏览器能打开。别因为"打不开"以为配置错了。
- **类 vs 实例**：`sensitive_point`（敏感点）是类（字典里的词）；"西山遗址"是实例（一个具体句子 的主语）。混着说会绕晕。
- **字面量没有 IRI**："500 米"是字面量，不能当主语再被描述；要描述"500 米"本身，得造一个节点——建模时常见纠结点。
