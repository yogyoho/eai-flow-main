```

│   ├── gb50016_2014_2018.md         # 建筑设计防火规范
│   ├── gb50058_2014.md              # 爆炸危险环境电力装置设计规范
│   ├── gb50116_2013.md              # 火灾自动报警系统设计规范
```

## 使用方法

### 1. 触发技能

当用户请求以下内容时自动触发：
- "合规校验"
- "消防规范检查"
- "GB标准符合性"
- "消防设计合规性"
- "检查消防设计"

### 2. 工作流程

1. **加载参考文档**：读取 `references/` 目录下的标准和清单
2. **提取设计参数**：从消防设计报告中提取关键参数
3. **运行自动检查**：执行 `compliance_checker.py` 脚本
4. **生成合规报告**：输出检查结果

### 3. 使用命令行

```bash
python /mnt/skills/public/fire-regulatory-compliance-check/scripts/compliance_checker.py \
  --report /mnt/user-data/workspace/fire_protection_report.docx \
  --output /mnt/user-data/workspace/compliance_report.md
```
