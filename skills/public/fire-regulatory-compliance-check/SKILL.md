# 消防法规合规校验技能

## 概述

此技能提供针对相关GB标准和国家法规的消防设计报告自动化合规校验。验证设计是否符合所有适用的规范要求。

## 何时使用此技能

**加载此技能的条件：**
- 用户请求消防设计合规校验
- 用户提及"合规校验"、"消防规范"、"GB标准符合性"
- 根据GB标准检查消防设计报告
- 验证火灾危险性分类、防火间距、消防设施

## 引用的核心标准

| 标准号 | 标准名称 | 关键要求 |
|--------|----------|----------|
| GB50160-2008（2018版） | 石油化工企业设计防火标准 | 石化工厂防火、布局、间距 |
| GB50016-2014（2018版） | 建筑设计防火规范 | 建筑防火、火灾危险性分类 |
| GB50058-2014 | 爆炸危险环境电力装置设计规范 | 危险区域电气装置 |
| GB50116-2013 | 火灾自动报警系统设计规范 | 火灾报警系统设计 |
| GB50140-2005 | 建筑灭火器配置设计规范 | 灭火器配置 |
| GB50974-2014 | 消防给水及消火栓系统技术规范 | 给水和消火栓系统 |
| 《中华人民共和国消防法》（2019修订） | 中华人民共和国消防法 | 法律要求 |

## 合规检查清单

### 1. 火灾危险性分类
- [ ] 根据GB50016核实建筑/生产火灾危险性分类
- [ ] 根据GB50016核实储存区分类
- [ ] GB50160石化工厂特殊要求

### 2. 建筑防火
- [ ] GB50016表3.2.1耐火等级合规性
- [ ] GB50016表5.2.1防火间距
- [ ] GB50016第5.3章建筑面积限制
- [ ] 防火分区要求

### 3. 防火间距
- [ ] 建筑间防火间距（GB50016）
- [ ] 设备间距（GB50160）
- [ ] 罐区间距（GB50160）

### 4. 消防给水
- [ ] 给水能力（GB50974）
- [ ] 室外消火栓间距（GB50974）
- [ ] 室内消火栓覆盖（GB50974）
- [ ] 消防水池/水箱容量

### 5. 火灾自动报警系统
- [ ] 探测器选型（GB50116）
- [ ] 探测器布置（GB50116）
- [ ] 手动报警按钮位置（GB50116）
- [ ] 控制系统要求

### 6. 灭火器
- [ ] 灭火器选型（GB50140）
- [ ] 保护距离（GB50140表5.2.1）
- [ ] 灭火器数量计算（GB50140）

### 7. 爆炸危险环境电气
- [ ] 区域划分（GB50058）
- [ ] 设备选型（GB50058）
- [ ] 布线方式（GB50058）
- [ ] 接地要求（GB50058）

### 8. 灭火救援设施
- [ ] 消防车道宽度和净空（GB50016）
- [ ] 消防车回转场地
- [ ] 消防救援通道

### 9. 法律合规
- [ ] 消防设计审查批准
- [ ] 施工许可合规
- [ ] 消防设施检查要求

## 工作流程

### 步骤1：加载合规参考文档

读取相关标准参考文件：
- `/mnt/skills/public/fire-regulatory-compliance-check/references/compliance_checklist.md`
- 各GB标准摘要文件（按需）：
  - `references/gb50160_2008_2018.md`
  - `references/gb50016_2014_2018.md`
  - `references/gb50058_2014.md`
  - `references/gb50116_2013.md`
  - `references/gb50140_2005.md`
  - `references/gb50974_2014.md`
  - `references/fire_law_2019.md`

### 步骤2：提取设计参数

从消防设计报告中提取：
- 建筑用途类型
- 火灾危险性分类
- 建筑面积和高度
- 耐火等级
- 间距
- 给水能力
- 设备数量

### 步骤3：运行自动检查

使用合规检查脚本：

```bash
python /mnt/skills/public/fire-regulatory-compliance-check/scripts/compliance_checker.py \
  --report /mnt/user-data/workspace/fire_protection_report.docx \
  --output /mnt/user-data/workspace/compliance_report.md
```

脚本将：
1. 解析报告内容
2. 提取设计参数
3. 对照各标准验证
4. 生成包含通过/失败状态的合规报告

### 步骤4：人工审查

对于每个失败的检查项：
1. 查阅标准中的具体要求
2. 评估设计是否满足要求
3. 如不合规，记录差异和推荐修复方案

### 步骤5：生成报告

生成合规验证报告：
- 所有检查项目摘要
- 每项要求的通过/失败状态
- 任何失败项的详细发现
- 整改建议

## 输出内容

合规检查输出应包括：

1. **合规摘要表**
   | 检查项目 | 标准 | 要求 | 状态 |

2. **详细发现**
   - 每个失败项：要求文本、实际值、期望值、建议

3. **建议**
   - 关键问题的优先修复
   - 最佳实践的改进建议

## 注意事项

- 始终使用标准的最新版本（2018版优先）
- 特别注意GB50160中的石化特殊要求
- 验证所有数值满足最低规范要求
- 如有设计偏差，需记录正当理由
- 附上工程计算作为支持证据
