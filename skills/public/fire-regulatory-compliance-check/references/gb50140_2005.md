# GB50140-2005 建筑灭火器配置设计规范

## 概述
适用于新建、扩建和改建建筑中灭火器配置设计。

## 主要内容

### 1. 火灾分类
| 类型 | 描述 |
|------|------|
| A类 | 固体物质火灾 |
| B类 | 液体或可熔化固体火灾 |
| C类 | 气体火灾 |
| D类 | 金属火灾 |
| E类 | 带电火灾 |

### 2. 危险等级划分
| 等级 | 场所举例 |
|------|----------|
| 严重危险级 | 广播电台、档案室、商场 |
| 中危险级 | 办公室、餐厅、旅馆 |
| 轻危险级 | 住宅、幼儿园、办公室 |

### 3. 灭火器选型
| 火灾类型 | 适用灭火器 |
|-----------|-------------|
| A类 | 水型、泡沫、磷酸铵盐干粉 |
| B类 | 泡沫、干粉、二氧化碳 |
| C类 | 干粉、二氧化碳 |
| D类 | 专用灭火器 |
| E类 | 干粉、二氧化碳 |

### 4. 配置计算
- 保护距离：严重危险级≤15m，中危险级≤20m，轻危险级≤25m
- 计算单元：按防火分区或楼层划分
- 修正系数：根据是否设置固定灭火系统确定
