# GB50116-2013 火灾自动报警系统设计规范

## 概述
适用于新建、扩建和改建建筑中火灾自动报警系统的设计。

## 主要内容

### 1. 系统形式
- **区域报警系统**：适用于小型建筑
- **集中报警系统**：适用于中型建筑
- **控制中心报警系统**：适用于大型建筑

### 2. 探测器选择
| 场所 | 探测器类型 |
|------|------------|
| 办公室、宿舍 | 感烟探测器 |
| 厨房、锅炉房 | 感温探测器 |
| 车库 | 感烟或感温探测器 |
| 电气设备间 | 感烟探测器 |

### 3. 探测器布置
- 保护面积：30-80㎡（根据高度）
- 间距：一般不超过8m
- 安装高度：≤12m（感烟），≤8m（感温）

### 4. 手动报警按钮
- 设置间距：≤30m
- 安装高度：1.3-1.5m
- 宜设置在疏散通道

### 5. 消防联动控制
- 消防泵启动
- 排烟风机启动
- 消防广播
- 火灾应急照明
