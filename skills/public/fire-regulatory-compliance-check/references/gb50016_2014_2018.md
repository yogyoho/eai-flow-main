# GB50016-2014 建筑设计防火规范（2018版）

## 概述
本标准适用于新建、扩建和改建的建筑防火设计。

## 主要内容

### 1. 术语
- 耐火等级：建筑构件承受火灾作用能力的分级
- 防火间距：相邻建筑之间防止火灾蔓延的最小距离
- 防火分区：采用防火分隔措施划分出的防火单元

### 2. 火灾危险性分类
#### 2.1 生产的火灾危险性分类
| 类别 | 典型条件 |
|------|----------|
| 甲类 | 闪点<28℃；爆炸下限<10% |
| 乙类 | 28℃≤闪点<60℃；爆炸下限≥10% |
| 丙类 | 闪点≥60℃ |
| 丁类 | 难燃物品 |
| 戊类 | 非燃物品 |

### 3. 耐火等级和耐火极限

| 构件 | 一级 | 二级 | 三级 | 四级 |
|------|------|------|------|------|
| 墙体 | 3.0h | 2.5h | 2.0h | 0.5h |
| 楼板 | 2.0h | 1.5h | 1.0h | - |
| 屋顶 | 1.5h | 1.0h | 0.5h | - |

### 4. 防火间距
- 民用建筑之间：6-13m（根据耐火等级）
- 工业建筑之间：根据火灾危险性类别确定

### 5. 消防车道
- 宽度≥4m
- 净空高度≥4m
- 环形车道或尽头式回车道

### 6. 消防救援设施
- 消防登高面
- 救援场地
- 消防电梯
