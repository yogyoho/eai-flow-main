# GB50160-2008 石油化工企业设计防火标准（2018版）

## 概述
本标准适用于石油化工企业新建、扩建和改建工程的防火设计。

## 主要内容

### 1. 术语和定义
- 石油化工企业：以石油、天然气为原料的化学工业企业
- 工艺装置：完成生产过程的设备和建筑物组合
- 储罐区：集中布置储罐的区域

### 2. 火灾危险性分类
#### 2.1 生产的火灾危险性分类
| 类别 | 典型物质 |
|------|----------|
| 甲A | 15℃时蒸气压>0.1MPa的烃类液体 |
| 甲B | 甲A类以外的可燃液体 |
| 乙A | 28℃≤闪点≤45℃ |
| 乙B | 45℃<闪点<60℃ |
| 丙A | 60℃≤闪点≤120℃ |
| 丙B | 闪点>120℃ |

#### 2.2 储存物品的火灾危险性分类
同生产的火灾危险性分类

### 3. 厂址选择与总平面布置
- 厂址应避开地震断裂带、地质灾害区
- 总平面应合理布置功能分区
- 防火间距应满足规范要求

### 4. 工艺装置
- 设备布置应符合工艺流程要求
- 防火间距应满足表5.2.1要求
- 安全疏散通道应畅通

### 5. 储罐区
- 储罐间距应满足规范要求
- 防火堤设置应符合要求
- 消防车道应畅通

### 6. 管道设计
- 管道设计压力确定
- 管道材料选用
- 管道绝热设计

### 7. 电气
- 爆炸危险区域划分
- 电气设备选型
- 防雷防静电

### 8. 消防设施
- 消防给水设计
- 泡沫灭火系统
- 干粉灭火系统
