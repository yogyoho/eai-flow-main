# 消防设计合规检查清单

## 1. 火灾危险性分类检查

### 1.1 生产火灾危险性分类（GB50016-2014）
- [ ] 甲类生产：闪点<28℃的液体；爆炸下限<10%的气体
- [ ] 乙类生产：28℃≤闪点<60℃的液体；爆炸下限≥10%的气体
- [ ] 丙类生产：闪点≥60℃的液体；可燃固体
- [ ] 丁类生产：难燃物品
- [ ] 戊类生产：非燃物品

### 1.2 储存物品火灾危险性分类（GB50016-2014）
- [ ] 甲类储存物品
- [ ] 乙类储存物品
- [ ] 丙类储存物品
- [ ] 丁类储存物品
- [ ] 戊类储存物品

### 1.3 石油化工特殊要求（GB50160-2008）
- [ ] 甲A类：15℃时蒸气压>0.1MPa的烃类液体
- [ ] 甲B类：甲A类以外的可燃液体
- [ ] 乙A类：28℃≤闪点≤45℃
- [ ] 乙B类：45℃<闪点<60℃
- [ ] 丙A类：60℃≤闪点≤120℃
- [ ] 丙B类：闪点>120℃

## 2. 建筑防火检查

### 2.1 耐火等级（GB50016-2014）
- [ ] 一级耐火等级：全部不燃构件
- [ ] 二级耐火等级：除吊顶外不燃构件
- [ ] 三级耐火等级：屋顶难燃构件
- [ ] 四级耐火等级：墙体难燃构件

### 2.2 防火间距（GB50016-2014 表5.2.1）
- [ ] 建筑之间防火间距
- [ ] 与相邻建筑间距
- [ ] 消防车道宽度

### 2.3 建筑层数和面积（GB50016-2014 第5.3章）
- [ ] 建筑层数限制
- [ ] 防火分区面积
- [ ] 每层允许面积

- [ ] 补水设施
- [ ] 吸水口设置

## 4. 火灾自动报警系统检查（GB50116-2013）

### 4.1 探测器选择
- [ ] 感烟探测器：适用于火灾初期产烟场所
- [ ] 感温探测器：适用于正常环境温度较高场所
- [ ] 手动报警按钮：设置位置和数量

### 4.2 探测器布置
- [ ] 探测器间距
- [ ] 探测器保护面积

- [ ] 报警控制器设置
- [ ] 消防联动控制
- [ ] 火灾应急广播

## 5. 灭火器配置检查（GB50140-2005）

### 5.1 危险等级确定
- [ ] 严重危险级
- [ ] 中危险级
- [ ] 轻危险级

### 5.2 灭火器选型
- [ ] A类火灾：水基型、干粉
- [ ] B类火灾：干粉、泡沫、二氧化碳
- [ ] C类火灾：干粉、二氧化碳
- [ ] D类火灾：专用灭火器

## 6. 爆炸危险环境电气检查（GB50058-2014）

### 6.1 爆炸危险区域划分
- [ ] 0区：连续出现或长期出现爆炸性气体
- [ ] 1区：正常运行时可能出现爆炸性气体
- [ ] 2区：正常运行时不可能出现爆炸性气体
- [ ] 20区：连续出现或长期出现爆炸性粉尘
- [ ] 21区：正常运行时可能出现爆炸性粉尘
- [ ] 22区：正常运行时不可能出现爆炸性粉尘

### 6.2 电气设备选型
- [ ] 防爆等级
- [ ] 防护等级
- [ ] 布线要求

### 6.3 接地要求
- [ ] 保护接地
- [ ] 防静电接地
- [ ] 等电位联结

---

## 7. 灭火救援设施检查（GB50016-2014）

### 7.1 消防车道
- [ ] 宽度≥4m
- [ ] 净空高度≥4m
- [ ] 坡度≤8%
- [ ] 环形车道或尽头式车道

### 7.2 消防回转场地
- [ ] 回转半径≥12m
- [ ] 承重能力

### 7.3 消防登高面
- [ ] 登高面长度
- [ ] 消防车道距离
