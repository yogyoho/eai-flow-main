# 消防设计专篇各章节编写指南

## 第1章 设计依据及采用的标准

### 1.1 设计依据
编写要点：
- 列出项目相关的批复文件、可行性研究报告、相关部门来函
- 引用设计基础资料名称和来源
- 注明开工会会议纪要和往来技术文件

格式示例：
```
a）《XX项目可行性研究报告》及批复；
b）《XX市安全生产监督管理局关于XX项目的函》；
c）《XX集团公司XX规定》；
d）（项目地区）提供的设计基础资料；
e）基础设计开工会会议纪要、工作函及往来邮件；
```

### 1.2 设计采用的技术标准、规范
编写要点：
- 按标准重要性和优先级排列
- 注明标准号和版本年份
- 特别注意2018版更新内容

格式示例：
```
石油化工企业设计防火标准（2018版）        GB50160-2008
建筑设计防火规范（2018版）                GB50016-2014
爆炸危险环境电力装置设计规范              GB50058-2014
火灾自动报警系统设计规范                  GB50116-2013
建筑灭火器配置设计规范                    GB50140-2005
消防给水及消火栓系统技术规范              GB50974-2014
```

### 1.3 地方相关法规
编写要点：
- 列出国家和地方相关法规
- 特别注明最新修订版本

## 第2章 概述

### 2.1 项目位置
编写要点：
- 明确项目所在具体位置
- 描述周边环境
- 注明占地面积

### 2.2 项目建设功能定位
编写要点：
- 描述项目建设目标
- 说明项目主要功能

### 2.3 建设规模
编写要点：
- 总建筑面积
- 主要建筑物规模
- 设备配置情况

### 2.4 建设内容
编写要点：
- 列表说明各类建筑物
- 包括功能性建筑和附属设施

编写要点：
- 明确新建/扩建/改建

表格格式：
| 序号 | 条件 | 单位 | 数值 |
|------|------|------|------|
| 1 | 温度 | | |
| | 年平均气温 | ℃ | XX |
| | 最热月平均气温 | ℃ | XX |
| ... | ... | ... | ... |

### 2.7 周围消防站情况
编写要点：
- 说明与周边消防站的距离
- 评估消防响应能力

| 序号 | 主项代号 | 名称 | 数量 | 主项专业 | 备注 |

| 2 | 200 | 消防水池及泵房 | 1 | 给排水 | |

### 3.2 火灾危险性分类
编写要点：
- 确定火灾危险等级（轻/中/严重）

## 第4章 防火安全措施

### 4.1 总平面布置、防火间距及消防通道
编写要点：
- 描述总平面布置方案
- 列出主要建筑物间距
- 说明消防车道设置

### 4.2 防雷、接地的设计原则
#### 4.2.1 防雷设计原则
编写要点：
- 确定防雷等级（按GB50057）
- 说明接闪器、引下线、接地体设置

#### 4.2.2 接地设计原则
编写要点：
- 说明接地系统构成（工作、保护、防雷、防静电）
- 列出接地电阻要求
- 说明等电位联结措施

### 4.3 供电安全
编写要点：
- 用电负荷等级和容量
- 供电电源情况
- 配电系统接线方式
- 照明设计
- 应急电源配置（UPS/EPS）

### 4.4 建、构筑物防火
编写要点：
- 建构筑物一览表（面积、高度、结构类型、火灾危险性、耐火等级）
- 防火措施
- 抗震措施（按GB50223）
- 节能措施（按GB50189）
- 装修材料要求

表格格式：
| 序号 | 名称 | 占地面积(㎡) | 建筑面积(㎡) | 层数/高度 | 火灾危险性 | 耐火等级 | 结构类型 | 备注 |
|------|------|-------------|-------------|-----------|------------|----------|----------|------|

### 4.5 建筑物通风措施
编写要点：
- 列表说明各建筑物通风系统
- 包含：换气次数、通风方式、风量、设备型号

表格格式：
| 建筑物名称 | 生产类别 | 电气防爆等级 | 主要有害物 | 换气次数 | 通风方式 | 风量(m³/h) | 系统编号 | 设备规格 |

## 编写注意事项

1. **数据准确性**：所有数值需经计算或核实
2. **标准时效性**：使用最新版本标准
3. **内容完整性**：8章内容需完整无遗漏
4. **格式规范性**：表格格式需统一规范
5. **专业性**：使用规范的专业术语
6. **合规性**：确保符合所有适用标准
