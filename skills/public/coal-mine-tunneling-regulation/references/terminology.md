# 煤矿掘进作业规程专业术语

> 编写报告时统一使用这些术语的规范写法，避免口语化/错别字。

## 巷道与工作面

- **掘进（drivage / heading）**：在煤岩中开凿巷道的作业。机掘=综掘机截割；炮掘=钻眼爆破。
- **顺槽（gateway / roadways）**：沿走向布置、服务回采工作面的巷道。**运输顺槽（进风顺槽）**运煤进风；**回风顺槽**回风运料。**切眼（开切眼）**是工作面起始安装巷道。
- **开口 / 拐弯 / 抹角**：巷道起点开口、转向、转角处的圆弧化处理（如 6m 半径抹角）。
- **方位角 / 方位**：巷道中线方向（度分秒）。
- **掘进断面 / 净断面（m²）**：掘进出来的毛断面 vs 支护后的有效断面。
- **迎头（掘进工作面）**：当前掘进的最前端。

## 煤岩层与地质

- **煤层赋存**：层位、时代（如二叠系下统山西组）、埋深、厚度、倾角。
- **顶板：老顶 / 直接顶；底板：直接底 / 老底**。老顶=坚硬不易冒落的岩层；直接顶=紧贴煤层、随采随冒。
- **单轴抗压强度（MPa）**：煤/岩石强度指标。
- **柱状图（综合柱状图）**：煤岩层自上而下的岩性柱状。
- **瓦斯**：甲烷为主。**绝对涌出量（m³/min）**、**相对涌出量（m³/t）**；矿井瓦斯等级（低/高/突出）。
- **煤尘爆炸性 / 煤自燃倾向性**：安全分类指标。
- **涌水量（m³/h）**：正常涌水量 / 最大涌水量。
- **"三区"管理**：可采区 / 缓采区 / 禁采区（防治水）。
- **"有掘必探，先探后掘"**：水害防治强制原则。

## 支护（技术核心，参数最敏感）

- **锚杆（rock bolt）**：型号如 `MSGLW-500/22×2400`（MG500 钢、公称直径 22mm、长 2400mm，左旋无纵筋螺纹钢）。
- **锚索（cable bolt）**：型号如 `SKP22-1/1860-7300`（1×7 或 1×19 股钢绞线、公称直径 22mm、抗拉强度 1860MPa、长 7300mm）。
- **间排距**：锚杆/锚索在同一排的间距、相邻排的排距（mm）。
- **预紧力（kN）/ 预紧扭矩（N·m）**：锚杆锚索安装时施加的初始张拉。锚索常用 ≥150kN / ≥250kN，并要求"超张拉"补偿预应力损失。
- **锚固力（kN）**：锚杆锚索不被拉出的最小抗力。
- **树脂锚固剂（resin cartridge）**：型号如 `MSCKb2335`（超快速、Φ23×350mm）、`MSZ2360`（中速、Φ23×600mm）。锚固方式：端锚 / 加长锚 / 全长锚。
- **护表构件**：**W 钢带**（如 `BHW235/280/4-4800-6`）、**钢筋梯子梁**（如 `Φ18-5-4700×250`）、**W 钢护板**、**托板/托盘**（如 `300×300×14` 可调心托板、`150×150×10` 拱形托板）。
- **网片**：**钢筋网**（Φ6.5，网孔 60×60mm）、**金属网/菱形网**（8# 铁丝，网孔 50×50mm）、**塑料网**。搭接长度、联网铁丝（双股 14#）、扭结圈数。
- **临时支护 / 永久支护**：前探梁 / 液压锚杆钻车（临时）；树脂锚固锚杆锚索系统（永久）。
- **复合支护**：U 型钢棚（如 29U）、注浆加固（过断层/老空/破碎带）。
- **工程质量允许偏差表**：毛宽/净宽、毛高/净高、间排距、预紧力等的设计值与允许偏差。

## 一通三防（通风、防瓦斯、防煤尘、防灭火）

- **局部通风机（局扇）**：压入式通风常用。**风筒**（抗静电阻燃柔性风筒，直径 Φ mm）。
- **需风量**：按瓦斯涌出、同时作业最多人数、一次爆破炸药量等分别计算取大值。
- **风速校核**：掘进巷道最低 0.25m/s、最高 4m/s。
- **风电闭锁 / 瓦斯电闭锁（"两闭锁"）/ 三专两闭锁**：安全供电联锁。
- **综合防尘**：湿式凿岩/截割、喷雾洒水、净化水幕、转载点喷雾、煤层注水、冲洗巷帮、个体防护（防尘口罩/噪声耳塞）。

## 安全监控（AQ 1029）

- **传感器**：甲烷（低浓/高浓）、一氧化碳、温度、风速、设备开停、风门开关。
- **报警值 / 断电值 / 复电值**：甲烷一般 ≥1.0% 报警、≥1.5% 断电、＜1.0% 复电（具体按矿与规程）。
- **断电范围**：掘进迎头及其回风流经区域、被串进的进风等。

## 供电与运输

- **电压等级**：井下高压 6kV/10kV、低压 1140V/660V/380V、照明信号 127V。
- **保护接地 / 过流保护 / 漏电保护**：三大保护。
- **运输**：刮板输送机、带式输送机（胶带）、矿车、无极绳/绞车。**一坡三挡**（倾斜巷道防跑车）。

## 应急与避灾

- **六大系统**：监测监控、人员定位、紧急避险（避难硐室）、压风自救、供水施救、通信联络。
- **避灾路线**：水灾"向上、向外"；火灾"迎新风、戴自救器"。区分进/回风路线。
- **自救器**：过滤式（CO）/ 化学氧 / 压缩氧。

## 标准引用缩写

- **GB** 国家标准、**GB/T** 国家推荐性、**AQ** 安全生产行业标准、**MT/T** 煤炭行业推荐性、**DZ/T** 地质矿产行业。
- **《煤矿安全规程》**：总纲，引用时写全称与版次（2022 年版）。
