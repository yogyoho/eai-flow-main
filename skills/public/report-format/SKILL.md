# 报告格式化技能

## 你的操作

### 第 1 步:确认输入文件
```
read_file(<报告路径>)
```
报告路径通常在 `/mnt/user-data/outputs/` 下,文件名含"消防设计专篇"。

### 第 2 步:运行格式化
```bash
python /mnt/skills/custom/report-format/scripts/format.py \
  <输入报告.md> \
  <输出报告_格式化.md> \
  /mnt/user-data/outputs/<项目名>_passport.json
```
第三个参数是 Report Passport（extract 生成的元数据文件）。format.py 会更新它记录格式化结果。

### 第 3 步:展示结果
```
present_files(filepaths=["<输出报告_格式化.md>"])
```
向用户报告:去了多少源编号、删了多少空节、生成了目录。

### 第 4 步:停止,问用户
**做完就停。** 问用户:"格式化完成。需要扩写(report-enrich)或润色(report-polish)吗?"
**不要自动调用下一个技能。**

## ⛔ 不要做的事
- **不要改文字内容**——format.py 只改结构(编号、空节、目录),不改任何一个字的正文。
- **不要自动链式调用 enrich/polish**——那些是生成性操作,必须用户显式触发。
- **不要在 extract 未完成时调用**——本技能的输入是 extract 的输出。

## 做了什么
1. **去源编号**: 段首 `11.4.1.1 防雷设计原则` → `防雷设计原则`
2. **重编号**: 按报告父节层级编 `4.3.1, 4.3.2...`
3. **删空节**: 只有标题没有内容的 section 整个删掉
4. **生成目录**: 在报告标题之后、第一章之前插入结构化目录
