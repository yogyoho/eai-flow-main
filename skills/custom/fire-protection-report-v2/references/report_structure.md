# 消防设计专篇报告结构

## 标准8章结构

| 章节 | 标题 | 主要内容 |
|------|------|----------|
| 1 | 设计依据及采用的标准 | 设计依据、技术标准规范、地方法规 |
| 2 | 概述 | 项目位置、功能定位、建设规模、气象条件 |
| 3 | 火灾危险性分析 | 主项表、火灾危险级分类 |
| 4 | 防火安全措施 | 总平面布置、防雷接地、供电安全、建筑防火、通风措施 |
| 5 | 消防设施 | 室外水消防、室内水消防、灭火器、火灾报警、视频监控 |
| 6 | 灭火救援设施 | 消防通道、回转场地 |
| 7 | 消防设施专项投资概算 | 投资估算表 |
| 8 | 图纸及表格 | 附图清单、设备表 |

## 各章节详细说明

### 第1章 设计依据及采用的标准

#### 1.1 设计依据
- 项目批复文件
- 可行性研究报告及批复
- 相关部门来函
- 设计基础资料
- 开工会会议纪要

#### 1.2 设计采用的技术标准、规范
- GB50160-2008（2018版）石油化工企业设计防火标准
- GB50016-2014（2018版）建筑设计防火规范
- GB50058-2014 爆炸危险环境电力装置设计规范
- GB50116-2013 火灾自动报警系统设计规范
- GB50140-2005 建筑灭火器配置设计规范
- GB50974-2014 消防给水及消火栓系统技术规范
- GB50057-2010 建筑物防雷设计规范
- GB50223-2008 建筑工程抗震设防分类标准
- GB50189-2015 公共建筑节能设计标准

#### 1.3 地方相关法规
- 《中华人民共和国消防法》（2019修订）
- 地方消防条例
